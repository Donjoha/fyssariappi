# Fysioterapia App – Web Prototype

Tämä on React + Vite -pohjainen fysioterapiasovelluksen prototyyppi, jossa on:

- Etusivu (kipu, energia, mieliala)
- Harjoitukset (video + ohjeet)
- Edistyminen (trendit + liikerata)
- Chat (asiakas ↔ terapeutti)
- Navigointi (React Router)
- Sinivihreä väripaletti mockupin mukaisesti
